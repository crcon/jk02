# 常州枢能分期扩容行动指导方案

这是常州枢能项目一期、二期扩容与接入路径的静态行动指导页面。

## 页面内容

- 一期由 150MW/300MWh（2 小时）技改为 150MW/600MWh（4 小时）的变更路径
- 二期 75MW/300MWh、35kV 接入现有经开数能项目的申报与接入安排
- 省网、接入批复、调度通信、保护及并网验收的变更清单
- 4 公里外线的距离、电流、线损和方案比选模型
- 成本与投入的手工录入模型

## 成本口径

页面不预置造价、投资或单价结论。使用者可录入：

- 外线距离（km）
- 单位造价（万元/km）
- 端点及固定投入（万元）
- 电价（元/kWh）

页面仅按录入值计算：

- 造价 = 距离 × 单位造价 + 固定投入
- 线损电量 = 线路电阻损耗 × 年等效满功率运行小时
- 年线损电费 = 年损耗电量 × 电价

最终造价、线路路径、设备参数和接入边界以设计院、供电公司及相关批复为准。
